# netdiag – сетевая диагностическая утилита для Linux

`netdiag` – это консольная программа на C для получения информации о сетевых интерфейсах, маршрутах, VLAN, проверки связности и сбора диагностического архива.

## Возможности

- Показать все сетевые интерфейсы (имя, состояние, MAC, MTU, IP-адреса)
- Показать таблицу маршрутизации IPv4
- Показать настройки VLAN (если активны)
- Проверить состояние линка интерфейса (carrier, скорость)
- Проверить доступность шлюза с помощью ping
- Собрать диагностический архив (tar.gz) с выводом ключевых команд
